# Run Namibia Sound Assets

Place your 10 MP3 sound files in this folder (`/public/sounds/`):

1. `lion.mp3` - Lion roar
2. `rhino.mp3` - Rhino snort
3. `elephant.mp3` - Elephant trumpet
4. `zebra.mp3` - Zebra whinny
5. `springbok.mp3` - Springbok bleat/grunt
6. `ostrich.mp3` - Ostrich boom
7. `crash.mp3` - Crash / impact sound
8. `coin.mp3` - Coin pickup sound
9. `gold.mp3` - Gold pickup sound
10. `diamond.mp3` - Diamond pickup sound

Note: If any MP3 is missing, the game's built-in Web Audio API synthesizer automatically generates an authentic sound so the game never crashes or remains silent.
